# Grama Khata Android Application

## Overview
The Grama Khata Android Application is developed to simplify village property record management and citizen services digitally. This project helps users manage property details, owner information, tax records, and related village administration tasks efficiently through a mobile application.

## Features
- User Login & Registration
- Property Record Management
- Owner Details Management
- Tax Information Display
- Search Property Records
- Easy User Interface
- Secure Data Storage
- Android Friendly Design

## Technologies Used
- Java / Kotlin
- Android Studio
- Firebase / SQLite
- XML
- Android SDK
